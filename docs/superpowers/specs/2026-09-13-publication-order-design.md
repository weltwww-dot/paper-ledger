# 论文发表时间倒序设计

## 目标

论文收录列表从上到下按发表时间排列，最新论文在最上方；筛选后仍遵循同一顺序。

## 非目标

- 不批量改写现有论文总结或 `data/papers.js` 中的日期原文。
- 不改变热点、趋势、筛选、展开收起、PDF 导航或本地存储行为。
- 不引入日期处理依赖，也不增加新的排序配置界面。

## 领域规则

「发表时间」指论文条目 `published` 字段表达的在线发表日期。

1. `YYYY-MM-DD` 与 `YYYY年M月D日` 都是日级精确日期；字段后附卷期、收稿或录用说明时，只解析开头的发表日期。
2. 日级精确日期按自然日倒序排列。
3. 只有年份的条目排在该年份所有日级精确日期之后、上一年份之前。
4. 空值、非法日期及无法识别的文本排在全部可识别日期之后。
5. 时间相同或同为无法识别时保持输入顺序，延续“同日按收录先后”的现有规则。

## 模块与接口

排序继续集中在 `ThemeStats` 模块的现有接口 `sortByPublished(list)`。调用方只传入论文列表并接收新的有序列表；接口不得修改输入数组。

日期识别和排序键生成属于该模块的内部实现，不新增外部接口。收录列表和趋势统计继续跨同一 seam 调用该接口，避免两套日期规则漂移。

## 数据流

1. `LedgerStore` 合并内置论文和用户论文，保留原始 `published` 文本。
2. 页面筛选生成当前论文集合。
3. `ThemeStats.sortByPublished` 将每条 `published` 转换为内部排序键并稳定倒序排列。
4. `renderLatest` 按排序结果渲染前四篇或全部论文。
5. 趋势计算复用同一排序接口选择最近论文。

## 异常与兼容

- 日期解析采用显式格式匹配，不依赖浏览器对中文日期的 `Date.parse` 实现差异。
- 月日越界的文本视为非法日期并沉底，不能通过字符串比较获得错误优先级。
- 现有 ISO 日期、带说明的 ISO 日期、中文日期、年份、空值和旧本地条目均可继续加载。
- 排序只影响展示与趋势选样，不改变持久化顺序，因此不会重写用户本地数据。

## 测试 seam 与验收

测试只通过公开接口 `ThemeStats.sortByPublished(list)` 和真实页面 DOM 观察行为。

- 单元回归：混合 ISO 日期、中文日期、带说明日期、年份、非法值和空值，断言排序规则及输入数组不变。
- 页面回归：在真实浏览器加载站点，展开全部收录后逐项读取可识别发表日期，确认顺序不递增且第一项为最新日期。
- 现有回归：布局不溢出、收起列表平滑返回顶部、PDF 新标签导航继续通过。
- 全量验收：项目 Python 测试、六道数据门禁、Node 语法检查、PDF 完整性检查及 `git diff --check` 全部通过。
