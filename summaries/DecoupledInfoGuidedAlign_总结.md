## 一句话概括

提出解耦信息引导的跨模态对齐框架 DIGCA，以多尺度上下文提取与多分支编码促成身份/模态信息的局部功能解耦，再据此引导跨流对齐，在 SYSU-MM01、RegDB 与 LLCM 上取得有竞争力的可见光—红外行人重识别性能。

## 问题与动机

可见光—红外行人重识别（VI-ReID）旨在昼夜全天候场景下跨可见光（VIS）与红外（IR）相机匹配行人，其首要困难是两种模态间巨大的跨模态差异：红外图像主要反映轮廓与热分布，与可见光在纹理、颜色等外观上天然不同，除单模态已有的类内差异与类间相似外还须克服模态鸿沟。现有工作沿特征解缠、跨模态对齐、注意力/多粒度建模三条路线推进，但在多数方法中功能化特征组织与后续对齐仍是被相对割裂的设计阶段：解缠方法关注区分模态共享与模态相关信息，却较少研究这些功能分化表示如何为目标化对齐提供引导；当身份相关信息与模态相关信息纠缠时，模态偏差可能干扰特征选择与聚合。为此作者提出"解耦引导对齐"策略：先组织信息倾向互补的表示，再用它们引导特征流交互，以缓解跨模态差异。

## 方法

论文提出三阶段解耦信息引导跨模态对齐（DIGCA）框架。其一，层级上下文提取器（HCE）借鉴 STDC 与 DSNet，以不同扩张率的空洞卷积配合残差连接聚合多尺度上下文信息（给出单层与堆叠感受野公式），丰富 ResNet 主干提取的初始身份表示。其二，多分支统一编码器（MBUE）含两条独立参数化的并行融合路径，每条路径由局部块（3×3 深度卷积、channels-last 层归一化、逐通道线性投影、GELU、残差）、全局块（受 Swin Transformer 启发的移位窗口多头自注意力 SW-MSA，含 LayerNorm/MLP 与 DropPath 残差）、普通 3×3 卷积及内嵌的 DIG-CMA 单元构成，输出 Branch0（原始流）与 Branch1、Branch2 三条互补特征流，促成身份相关与模态相关信息的"部分功能解耦"而非严格分离。其三，解耦信息引导跨模态对齐模块（DIG-CMA）先用 1×1 卷积对齐通道，再分别以通道注意力（全局平均池化 + 1×1 卷积 + ReLU + Sigmoid）精化全局特征、以空间注意力（最大/平均池化拼接 + 7×7 卷积 + Sigmoid）精化局部特征，通过交叉注意力（q 取自全局、k/v 取自局部对齐特征）建模相关性，用可学习权重 α、β、γ（softmax 归一化、和为 1）动态融合后经小波变换卷积（WTConv2d）残差增强。联合优化目标在继承 DEEN 的交叉熵、难样本三元组（margin 0.3）、中心引导难对挖掘 CPM（mc=0.2）与正交性损失之外，对三条流施加判别性中心损失 DCL（权重 λ3=0.1），总损失按式(20)加权（λ1=0.8、λ2=0.01）联合优化。

## 实验与结果

在 SYSU-MM01（491 身份、303,420 张图像，四台 VIS 两台 IR 相机，395/96 划分，All/Indoor Search 各 10 次 gallery 抽样）、RegDB（412 身份 8,240 张，206/206 划分，VIS-to-IR 与 IR-to-VIS 取 10 次划分均值）与低光照 LLCM（1,064 身份 46,767 张，九台相机，713/351 划分）上按标准协议评测 CMC R1/R10/R20 与 mAP。实现采用 ImageNet 预训练 ResNet-50 骨干、输入 384×192、SGD Nesterov（momentum 0.9、weight decay 5×10⁻⁴）、150 epoch、每批 6 身份 ×（4 VIS + 4 IR），单卡 RTX A6000。SYSU-MM01 上 DIGCA 取得 All Search 76.4% mAP / 79.3% R1（R10 98.3%、R20 99.5%）与 Indoor Search 88.8% mAP / 87.2% R1，比 TMD 高 5.4/8.7 个百分点、比 MHN 高 4.3/4.6、比 AMML 高 1.5/1.6、比 DEEN+DiVE 高 0.3/1.5；三次随机种子稳定性为 All 79.33±0.41 R1 / 76.37±0.24 mAP、Indoor 87.19±0.46 / 88.81±0.34。RegDB 上 VIS-to-IR 达 92.0% R1 / 85.3% mAP，IR-to-VIS 为 91.1% R1 / 84.5% mAP，VIS-to-IR R1 仍比 TMD 低 1.0 个百分点。LLCM 上 VIS-to-IR 57.9% R1 / 64.6% mAP、IR-to-VIS 70.5% R1 / 57.5% mAP，在 VIS-to-IR 上超过最强对比方法 MHN 1.3 个点 R1，IR-to-VIS 的 R1 与 mAP 分别比对比最高值高 0.8 与 2.0 个点。消融（SYSU-MM01，seed 0）显示 HCE、MBUE、DIG-CMA、DCL 逐项带来提升（完整配置 All 79.5/76.4、Indoor 87.6/89.0），WTConv 约增益 All Search 0.80 R1/0.69 mAP、Indoor 0.83/0.65 但 Indoor R10 略降 0.15；交叉注意力相对固定均值融合增益 1.62/1.23（All）与 1.15/0.77（Indoor）；全局+局部双源优于单一分支（All Search 相对 global-only 高 1.10 R1/2.23 mAP，相对 local-only 高 1.89/3.45），λ3=0.1 最优。特征分析表明 Branch1/2 的线性模态可解码性（平衡准确率）比 Branch0 低 4.58–7.57 个百分点、HSIC 更低，同时保持相近检索性能与正身份裕度（置换检验 p=0.005），验证了部分功能解耦。效率上 DIGCA 参数量 126.21M、FLOPs 37.08G、推理延迟 11.36 ms、峰值显存 32.86 GB，相对 DEEN（89.04M/18.47G/5.54 ms/29.72 GB）增加 37.17M 参数与 18.61G FLOPs；相对 HOS-Net（132.49M/9.16G/13.34 ms）参数少 6.28M、延迟低 1.98 ms，但 FLOPs 与显存更高。可视化显示 DIGCA 将类间/类内均值距离差扩大至 δ3=0.4280，LLCM 低光照 Rank-10 检索错误匹配更少。

## 贡献与局限

贡献：提出面向 VI-ReID 的解耦引导对齐策略，主张先用功能分化的互补表示引导后续跨流交互；设计 HCE 以扩张卷积+残差聚合多尺度上下文丰富初始表示；设计 MBUE，以并行全局关系与局部空间建模组织互补流并促成身份/模态信息的局部功能解耦；设计 DIG-CMA，以通道与空间注意力分别精化两条流、经交叉注意力与可学习动态融合（WTConv 增强）实现引导式跨模态对齐；在 SYSU-MM01、RegDB、LLCM 上以较全面实验（稳定性、消融、解耦性分析、效率与可视化）验证有效性。

局限：其一，依赖可靠的跨模态身份标注，而异构或视野不重叠相机难以提供可靠标注，缺失标注还可能把未标注正样本当作负样本引入监督噪声（论文以 LLCM 检索结果示意）；其二，相对 DEEN 增加的计算开销可能限制实时或资源受限部署，且评测仅覆盖三个基准，未充分涵盖更多样的相机网络、光照与采集条件。未来工作拟探索不确定感知伪标注、鲁棒目标函数与时间/相机元数据，以及参数共享、轻量注意力、自适应流选择与知识蒸馏等轻量化手段，并在更丰富的跨模态条件下评测。
