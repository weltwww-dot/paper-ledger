## 一句话概括

Disjunctive dynamic searchable symmetric encryption (DDSSE) is a promising technique that enables more expressive query capabilities over encrypted data while ensuring data security in dynamic update scenarios. While several schemes have been proposed to improve security and search efficiency, they still suffer from significant limitations, including high communication overhead and additional leakage during updates and queries. In this work, we initiate a formal study of disjunctive searchable symmetric encryption in the dynamic setting by refining its security model, including precise leakage functions and privacy notions. Based on this improved security notion, we propose a new DDSSE scheme, called D2SSE, which achieves both forward and backward privacy while incurring low leakage. Specifically, starting from the static TWINSSE framework which reduces dis junctive keyword queries to conjunctive meta-keyword queries, we extend it to support dynamic updates while preserving correctness. At the same time, we simultaneously mitigate keyword pair result pattern leakage and provide strong forward and backward privacy guarantees based on the combination of symmetric subset predicate encryption and puncturable encryption. Experimental results on the Wikimedia dataset show that D2SSE achieves a 0.25× reduction in search latency compared to the state-of-the-art scheme DIEX. Moreover, D2SSE requires only about 0.06× more client-side storage overhead of DIEX while maintaining comparable server-side storage cost.
