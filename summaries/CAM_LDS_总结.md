# CAM-LDS 总结

## 基本信息

- **标题**: CAM-LDS: cyber attack manifestations for automatic interpretation of system logs and security alerts
- **作者**: Max Landauer, Wolfgang Hotwagner, Thorina Boenke, Florian Skopik
- **期刊 / 会议**: IJIS 2026
- **发表**: 2026-08-26
- **内容状态**: 完整
- **研究方向**: 信息安全
- **DOI**: 10.1007/s10207-026-01318-x
- **PDF**: [IJIS_2026_CAM_LDS.pdf](papers/IJIS_2026_CAM_LDS.pdf)

## 一句话概括

发布 CAM-LDS：一个完全开源、可复现的 Linux 系统日志与安全告警数据集，用于分析和研究网络攻击在日志中的表现，支撑大语言模型对日志的自动语义解释。

## 问题与动机

日志数据对入侵检测与取证至关重要，但人工分析因数据量大、事件格式异构、消息非结构化而繁琐。现有自动化方法仍依赖领域特定配置（专家规则、手工解析器、人工特征工程），且难以语义理解日志并解释根因；大语言模型可实现与领域和格式无关的日志解释，但覆盖广泛攻击技术的公开标注数据集稀缺。

## 方法

构建并开源 Linux 环境下的网络攻击表现日志数据集：与现有数据集（多为网络中心、Windows 焦点或攻击多样性有限）不同，CAM-LDS 覆盖多种攻击技术，支持系统日志与安全告警的自动化解释研究，可直接用于 LLM 的评估与微调。

## 实验与结果

原文以数据集构建与开源为主；摘要未提供量化对比数字。

## 贡献与局限

- 贡献一：首个面向攻击表现自动解释、完全开源可复现的 Linux 日志数据集。
- 贡献二：填补 LLM 日志语义解释研究缺乏覆盖广泛攻击类型的标注数据这一空白。
- 局限：具体规模与评测数字原文摘要未提供；数据集覆盖面仍需社区持续扩展。
