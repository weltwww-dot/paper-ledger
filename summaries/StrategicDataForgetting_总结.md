## 一句话概括

本文面向联邦遗忘（FUL）提出一种基于前景理论（PT）数据遗忘博弈的、考虑 FL 服务器有限理性的诚实激励方案，通过惩罚与零支付机制抑制客户端自私行为并激励其保留更多数据。

## 问题与动机

联邦学习（FL）通过只交换模型参数保护隐私，但难以满足用户"被遗忘权"（GDPR、CCPA 等要求）。从头重训模型代价高昂，联邦遗忘（FUL）通过选择性移除特定用户数据对已训练模型的影响来实现 RTBF。然而现有 FUL 研究大多只关注遗忘技术本身，很少激励留存客户端参与、抑制其自私行为；同时普遍假设 FL 服务器是完全理性的决策者，忽略了其在风险与不确定性下的有限理性（如对低概率风险事件赋予过高的主观权重）；且多数方案只考虑全部撤销数据、不考虑部分撤销，也缺乏对提供无意义模型的客户的惩罚机制。本文旨在解决上述激励设计与有限理性建模的开放挑战。

## 方法

作者提出一个考虑 FL 服务器有限理性的策略式数据遗忘方案。首先设计实用的 FUL 框架：有界理性的服务器允许客户端部分撤销数据，并基于 influence function 比较遗忘前后模型更新的幅度来评估每个留存客户端的剩余数据量（量化到 H+1 个等级，d∈{−1,0,…,H}，含退出状态 −1 与无意义模型 0），评估误差记为 λ。其次构建基于前景理论（PT）的数据遗忘博弈：服务器作为领导者设计"剩余数据量—奖励"招募策略，客户端作为追随者选择最优剩余数据量以最大化自身效用；用 Prelec 权重函数 ω(Pr)=exp(−(−ln Pr)^α) 刻画服务器的概率权重扭曲效应（α 表示理性程度），并以主观期望效用替代期望效用理论（EUT）下的客观期望。客户端效用＝奖励−隐私成本(φᵢ,₁τᵢdᵢ)−训练成本(φᵢ,₂Tdᵢ)，服务器效用＝满意度 θᵢG(dᵢ)−奖励支出。同时设计惩罚机制（对提供无意义模型的客户端罚款 r₀=−R）与零支付机制（仅奖励参与 FUL 的客户端 r₋₁=0）以保证公平并抑制自私行为。作者分别分析 H=1（Scenario I）与 H=2（Scenario II）两种剩余数据量等级情形下的博弈均衡（命题与定理给出均衡条件与最优奖励闭式），并给出 O(H+I′) 复杂度的奖励分配算法（Algorithm 1/2）。

## 实验与结果

仿真采用 1 个 FL 服务器和 I=10 个客户端，训练成本设为 Ci(1)∼Γ(8,12)、Ci(0)∼Γ(1,2)，PT 行为参数 α∈[0.7,0.9]，评估误差 λ∈[0.1,0.3]，满意度权重取 10。数据集使用 MNIST、CIFAR-10 与 Tiny-ImageNet（前两者用定制 CNN，Tiny-ImageNet 用 ResNet-18），学习率 0.001、本地 batch size 64、全局遗忘轮数 50，并在 IID 与非 IID 场景下对比拍卖方案（AS）与随机方案（RS）。结果显示：最优奖励随服务器理性程度 α 提高而下降、随评估误差 λ 增大而上升（λ=0.20/0.25/0.30）；所提方案在剩余数据量指数（Fig. 3）与客户端平均效用（Fig. 5）上均优于 AS 与 RS；服务器效用随评估误差增大而下降、随理性程度（α=0.70/0.85/0.90）增大而上升；在 MNIST 与 CIFAR-10 非 IID 条件下训练损失低于基准；与理想 EUT 情形相比，PT 情形的全局模型精度略低，反映了服务器有限理性对 FUL 性能的负面影响；此外将所提激励方案与 Hessian-based FUL（HFU）、influence-based FUL（IFU）和部分重训（PRM）三种遗忘方法结合（Table II），在 CIFAR-10 与 Tiny-ImageNet 上仍保持有效，说明其泛化性。

## 贡献与局限

主要贡献有三：(1) 提出支持部分数据撤销、兼顾服务器有限理性的实用 FUL 框架及诚实激励机制；(2) 提出基于 PT 的数据遗忘博弈，刻画有界理性服务器在不确定与风险下的决策，并配套惩罚机制与零支付机制分别抑制自私行为、保证奖励公平；(3) 通过大量仿真验证方案在激励客户端提供高质量模型、抑制自私行为及提升遗忘模型效用上的有效性。局限方面：论文假设客户端数据 IID 以支撑 influence function 的剩余数据量评估（虽说明非 IID 可通过表示层差异方法扩展且评估与激励解耦）；假设客户端不共谋，共谋恶意客户端威胁、鲁棒 FUL 激励（如针对共谋的系统安全增强）被列为未来工作。
