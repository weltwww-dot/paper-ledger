# Instruction Learning Paradigms 总结

## 基本信息

- **标题**: Instruction Learning Paradigms: A Dual Perspective on White-Box and Black-Box LLMs
- **研究方向**: 人工智能
- **作者**: Yanwei Ren, Liu Liu, Baosheng Yu, Jiayan Qiu, Quan Chen
- **期刊 / 会议**: Machine Learning 2026
- **发表**: 2026-08-22
- **DOI**: 10.1007/s10994-026-07137-4
- **arXiv**: 2506.21573
- **PDF**: [ML_2026_InstructionLearning.pdf](papers/ML_2026_InstructionLearning.pdf)

## 一句话概括

提出一个融合白盒与黑盒大语言模型优点的指令优化框架：黑盒模型提供高质量多样化的指令初始化，白盒模型提供隐藏状态与输出特征的细粒度可解释性，两者在共享语义空间中融合并迭代优化。

## 问题与动机

指令（instruction）优化对释放大语言模型在复杂任务上的潜力至关重要。但纯白盒方法计算资源需求大、表征能力受限；纯黑盒方法可能产生高昂的调用成本。单一范式难以兼顾质量、可解释性与成本。

## 方法

通过语义相似性约束把黑盒与白盒表征融合到统一的高维语义空间：黑盒负责高质量、多样的指令初始化，白盒通过隐藏状态与输出特征提供细粒度解释；特征适配模块动态捕捉模型间的一致性与互补性，增强信息融合与语义鲁棒性，并支持迭代式指令优化。

## 实验与结果

在一系列基准任务上评测，涵盖复杂推理与三个英译 X 翻译任务；与强基线相比，该方法在平均性能上持续领先（原文摘要未给出具体数字）。

## 贡献与局限

- 贡献一：首次系统融合白盒与黑盒两种指令优化范式，兼顾初始化质量与语义可解释性。
- 贡献二：共享语义空间 + 特征适配模块的迭代优化框架，跨任务可扩展。
- 局限：具体性能数字原文摘要未提供；更大规模模型上的成本与收益仍需验证。
