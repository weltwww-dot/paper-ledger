## 一句话概括

本文通过受控基础设施实验（VoIP、SIP 中继）结合 332 人用户调研，从社会技术视角揭示来电显示（Caller ID）伪造的有效性源于基础设施层信任传播与用户层认知信任线索的交互。

## 问题与动机

Caller ID 伪造仍是跨 IP 电话与移动网络的电话诈骗和社会工程攻击（如 vishing）的关键使能技术。现有研究大多只分析信令漏洞或检测机制，少有实验系统评估不同电话基础设施在身份被篡改时如何接受与传播呼叫身份，也很少结合用户感知。此外 STIR/SHAKEN 等缓解框架依赖公钥基础设施，部署与扩展困难且仅覆盖 IP 环境，遗留的 SS7 等系统不在其保护范围。作者由此提出联合基础设施实验与大规模用户调查的统一社会技术分析，以解释伪造来电为何既技术上可行又认知上可信。

## 方法

技术部分在受控电话环境中实验评估三类场景：VoIP 环境（基于 Asterisk 22.1.1 与 FreePBX 17.0.19.23、Zoiper SIP 客户端），分别在 SIP 客户端级、PBX 级与 SIP 协议级篡改呼叫身份；SIP 中继互联场景，对比两个策略不同的商业中继提供商（Provider A 宽松全局可路由、Provider B 仅限西班牙号码空间）；SIM Box 移动网络场景则以文献综述方式分析。每场景重复十次，观测标准是发起端配置/篡改的标识与最终呈现给接收端的标识是否一致。用户部分采用基于情景（vignette）的问卷：332 名参与者对 5 个呼叫情景（屏幕显示银行名称、官方客服号码、未知号码、国际前缀、与本人号码相似）与 2 个 SMS 情景，用五点 Likert 量表评估接听、感知合法性、遵循指示的可能性；统计采用非参数方法（Friedman、Spearman、Mann-Whitney U，α=0.05）。全部实验材料与数据公开于 GitHub 仓库。

## 实验与结果

VoIP 场景中，宽松验证策略下客户端配置的伪造身份被无修改传播，默认 Asterisk 配置则在十次重复中全部以 SIP 401 拒绝未认证的 INVITE；PBX 级与协议级篡改在宽松配置下均稳定成功。中继对比中 Provider A 十次任意外地来电身份（如 +34 900 001 000、+1 555 123 4567）全部被接受并传播，Provider B 因路由限制将国际号码改写为默认西班牙号码，但国内号码空间内的伪造仍可行——作者强调路由限制并非安全机制。用户样本中 88.55% 使用网上银行，但仅 36.75% 知晓"telephone spoofing"术语、24.10% 知晓 smishing；57.2% 认为伪造可行。Friedman 检验显示五个情景在所有行为维度差异高度显著（接听 χ²(4)=481.18、合法性 χ²(4)=517.22、遵循指示 χ²(4)=390.23，均 p<0.001；Kendall's W=0.29–0.39）。Spearman 相关显示网络安全知识与遵循指示显著负相关（情景 1 ρ=−0.113、情景 3 ρ=−0.147、情景 5 ρ=−0.117），但与接听和合法性感知无关；教育水平与接听（ρ=0.215, p<0.001）、合法性（ρ=0.183, p<0.001）正相关。核心发现是行为上的"接触 vs 遵从"分离：情境信任线索影响是否接听/认为合法，而知识与意识主要降低遵循指示的意愿。防御评估中 Asterisk 的凭据认证、From 头校验与 Caller-ID 重写均实现 100% 缓解（十次全阻断/改写），STIR/SHAKEN 因部署不完整未做直接测试。

## 贡献与局限

贡献：对 VoIP、SIP 中继与移动网络三类环境的来电显示伪造进行了系统的受控实验评估；提供基于情景的用户感知与行为实证分析；提出联结基础设施信任传播与用户认知信任线索的社会技术框架；实证证明接听（engagement）与遵从（compliance）之间存在行为分离，为多层次防护策略提供依据。局限：实验限于受控环境，未对真实用户实施实际攻击（伦理与法律约束），用户影响仅通过模拟情景调查测得；样本经学术与线上渠道招募，教育水平偏高、不完全代表总体；行为数据为自报意图而非真实行动；统计结果支持关联解释但不建立因果关系；SIM Box 部分为文献分析而非直接实验；VoIP/PBX 仅覆盖 Asterisk/FreePBX 等代表性平台，不宣称普适性。
