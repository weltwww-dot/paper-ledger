## 一句话概括

提出稠密仿射变换卷积网络 DATCNN，在保留 KAN 符号回归能力与可解释性的同时兼容成熟 CNN 理论，在函数拟合、图像分类与自然语言处理任务上以更快训练速度取得更优或相当的性能。

## 问题与动机

近年来人工智能模型的可解释性日益受到重视：示例、归因、隐藏语义等解释方式都是间接的，规则式解释表达能力有限，因而支持数学表达式的符号回归逐步成为主流，但多数符号回归方法搜索空间随模型规模急剧膨胀。Kolmogorov-Arnold Network（KAN）以可学习激活函数直接学习每个单变量函数、避免大搜索空间，支持符号回归并提供良好的可解释性，其衍生模型在图像分割、时序预测等任务上表现不俗；但 KAN 存在收敛慢、训练困难等显著缺陷——其 B 样条结点向量 ξ 靠规则而非梯度下降优化，且 B 样条本身计算复杂。更重要的是，KAN 与 MLP/CNN 存在本质结构差异，缺乏灵活性，现有加速训练的成熟方法难以直接迁移，且缺少理论与经验保证。改进变体如 fKAN（可训练 Jacobi 基函数）和 PowerMLP（固定 ReLUk）仍存在性能受真值形式影响、灵活性不足或精度折衷等问题；将 KAN 直接插入 CNN（如 Convolutional KAN）也会把上述缺点带入模型。

## 方法

DATCNN 由多个 DATCNN 层堆叠而成，每层采用主干加残差连接的双路径结构：主干由多个“卷积 + 批归一化 + 激活”堆叠后再接一个无激活的全连接层构成，残差路径在输入输出同维时用恒等映射、异维时用全连接层，批归一化与激活均可选。DATCNN 的卷积通常是“稠密”的，即卷积核数远大于输入与输出维数，从而可将“卷积与激活函数的复合”看作激活函数的仿射变换：大量经仿射变换的激活函数构成可学习激活函数的基础，使 DATCNN 具备符号回归能力与可解释性。理论上，作者先证明均匀结点 B 样条具有平移对称性（定理 1），再定义归一化 B 函数（只需计算一次、训练推理期间固定的分段多项式）并证明任意 B 样条都可由归一化 B 函数经缩放平移表示（定理 3），进而给出其非递归系数计算法（命题 4）；随后证明一个由“核大小为 1 的一维卷积 + 归一化 B 函数激活 + 全连接 + SiLU/全连接残差”组成的卷积网络 DATCNNKAN 与均匀结点 KAN 层严格等价（定理 5）。在保持符号回归能力的前提下，DATCNN 将归一化 B 函数替换为导数性质更好的 SiLU 激活、按 ResNet 思路精简残差连接、在主干卷积后与残差路径全连接后加批归一化并允许卷积层堆叠，从而消除 KAN 的网格结构并改用梯度优化。符号回归时先训练 DATCNN，再抽取其主干参数解释为可学习激活函数、转换为 KAN 并沿用 KAN 的符号回归流程。

## 实验与结果

数值仿真验证理论：用长度 100,000 的随机数组检验定理 3，不同结点间距/阶数/网格数下相对误差仅 6.3e-31～7.2e-18；用形状 1000×dI 的随机输入检验定理 5，相对误差 0～5.3e-18，均处于舍入误差范围；非均匀网格默认 2% 非均匀度下近似误差约 6.61e-4，即使增至 20% 也仅约 5.90e-3，说明结论在非均匀度不超过 20% 时近似成立。函数拟合在 Feynman 与特殊函数数据集（共 129 个函数块）上进行：Feynman 上 DATCNN 平均 RMSE 0.0025、平均训练 152 s（KAN 0.0032/639 s，fKAN 0.0225/403 s，PowerMLP 0.0084/128 s）；特殊函数上 DATCNN 0.0034/174 s（KAN 0.0027/448 s，fKAN 0.0180/474 s，PowerMLP 0.0467/124 s）；DATCNN 的 RMSE 标准差最低（0.0043 与 0.0096），稳定性最好。Friedman + Nemenyi 检验（α=0.05，CD=0.413）显示：测试 RMSE 上 DATCNN 与 KAN 无显著差异且两者显著优于 PowerMLP、fKAN；训练时间上 DATCNN 与 PowerMLP 无显著差异，但显著快于 KAN 与 fKAN；平均秩图中 DATCNN 为（RMSE 1.605，时间 1.620）。在 Feynman I.8.4 上的消融表明批归一化、SiLU 激活与卷积层加深依次降低误差（RMSE 由 0.0050 降至 0.0023，KAN 为 0.0056/570 s），在 I.6.20b 上的超参数敏感性实验显示网络宽度、深度、卷积层数与学习率在较大范围内都稳定。图像分类在 Fashion-MNIST 与 SVHN（各含 Small/Medium/Big 三种规模）上沿用 Convolutional KAN 框架替换 KAN 层：Fashion-MNIST Big 上 DATCNN 准确率 0.9067、F1 0.9060、69 s/epoch（KAN 0.9027/0.9026、107 s，fKAN 0.8996、130 s，PowerMLP 0.8986、55 s）；SVHN Big 上 DATCNN 准确率 0.8844、F1 0.8727、82 s/epoch（KAN 0.8634/0.8504、152 s，fKAN 0.8841/0.8729、138 s，PowerMLP 0.8756/0.8642、75 s），多数配置下 DATCNN 精度领先且训练快于 KAN 与 fKAN。NLP 方面，在 TREC-6/TREC-50（5,450 训练/500 验证/500 测试）上用平均 GloVe 向量做问句分类，在 STS-B（5,750/1,500/1,380）上用 sentence-transformer 向量做语义相似度回归（Adam、学习率 1e-3、10 epoch、宽度 5、深度 2–6）：TREC-6 上 DATCNN 准确率 0.9560、F1 0.9625、31 s（KAN 0.9260 但需 5,985 s，fKAN 0.9600/101 s，PowerMLP 0.9520/24 s）；TREC-50 上 DATCNN 0.7500、F1 0.6186、32 s（KAN 0.7200、F1 0.5175、16,839 s，PowerMLP 0.7120，fKAN 0.5180）；STS-B 上 DATCNN 的 MAE 0.2725、RMSE 0.3478、Pearson 0.9759、Spearman 0.9759、67 s（KAN Pearson 0.5527、19,562 s，PowerMLP 0.9420/40 s，fKAN 0.8801/191 s）。300 维嵌入使 KAN 训练时间比其他模型高数个数量级，暴露了其计算图随输入维数激增的固有局限。

## 贡献与局限

主要贡献：提出新型卷积网络 DATCNN，通过“与 KAN 等价的卷积结构 + 具体增强”继承 KAN 的符号回归与可解释性优势，同时显著提升灵活性，可与既有 CNN 理论与训练技巧（批归一化、残差、卷积堆叠、梯度优化等）兼容，训练更快；为架构建立数学理论（均匀结点平移对称性、归一化 B 函数分解、DATCNNKAN 与 KAN 层等价定理），从理论上保证符号回归与可解释性能力；在多类任务上的大量实验表明其在精度（或与 KAN 相当的精度）下显著缩短训练延迟，并在图像分类与 NLP 任务上全面优于 KAN 及其变体。局限方面：严格的等价性证明基于均匀结点假设，非均匀网格下结论只是近似成立（实验覆盖至 20% 非均匀度）；函数拟合中 DATCNN 与 KAN 的测试 RMSE 无显著差异，其优势主要体现在训练速度与稳定性；文中消融、超参分析等以部分 Feynman 公式为样本，通用迁移性仍需在更大规模任务与数据上进一步验证。
