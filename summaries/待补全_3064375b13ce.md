## 一句话概括

Class imbalance is one of the primary challenges faced by machine learning-based network intrusion detection systems (NIDS), particularly when identifying rare yet high-risk attack types. Traditional oversampling techniques, such as random oversampling and SMOTE, often disrupt the inherent manifold structure of the data and introduce noise near class boundaries, thereby degrading detection performance for minority classes. To address this problem, this paper introduce the ADEO framework-an adaptive DBSCAN-enhanced oversampling method that effectively mitigates these issues by combining deep reinforcement learning with boundary-aware geometric modeling. The framework utilizes a Deep Q-Network (DQN) to automatically optimize DBSCAN parameters, enabling accurate identification of natural clustering structures within heterogeneous intrusion datasets. Building upon this foundation, ADEO constructs precise class boundary functions using methods such as convex hulls, minimum enclosing ellipses, or axis-aligned bounding boxes. It then generates samples within these constrained safe regions, preserving the true topological structure while avoiding noise near decision boundaries. Furthermore, this paper introduces hierarchical class mapping strategies and attack-specific feature engineering to enhance the framework's adaptability to different attack families. Experimental results on the NSL-KDD, UNSW-NB15, and CICIDS2017 benchmark datasets demonstrate that ADEO outperforms mainstream oversampling methods in terms of precision, accuracy, recall, F1 score, FPR, and AUC. Particularly notable improvements are achieved for extreme minority classes like Backdoor and Heartbleed, validating the proposed framework's effectiveness and efficiency in practical NIDS applications.
