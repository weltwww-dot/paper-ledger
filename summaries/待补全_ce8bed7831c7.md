## 一句话概括

Sparse4D 以稀疏 4D instance 为核心，把显式 3D anchor、隐式 instance feature、多视角空间融合和长时序传播统一到端到端感知框架中，在 nuScenes 上同时覆盖 3D 检测、跟踪和多模态感知，并兼顾性能与效率。

## 问题与动机

主流 BEV 方法需构造稠密鸟瞰特征，感知范围扩大时计算量随之增加，部署到低成本边缘设备困难；已有稀疏方法虽更高效，却与 BEV 方法存在性能差距，也难以直接完成高质量 3D 多目标跟踪。论文因此希望用对象级稀疏表示完成多传感器、时序和检测—跟踪一体化，减少后处理和内存开销。

## 方法

Sparse4D 将每个 instance 解耦为结构化 anchor 与高维 feature，anchor 通过 MLP 编码。空间上，deformable aggregation 从每个 3D anchor 产生固定/可学习 keypoints，经相机投影和双线性采样取得多视角、多尺度图像特征，再动态加权融合；其 EDA CUDA 实现把采样和加权合并以减少 HBM 访问。时间上，只更新传播 instance 的 anchor（补偿目标速度和 ego pose），保留 feature，从而以递归方式实现长期融合；通过 confidence threshold 锁定轨迹 ID，并扩展到 LiDAR 与相机多模态融合。

## 实验与结果

实验使用包含 1,000 个场景的 nuScenes（700/150/150 个训练、验证、测试场景）。在验证集 ResNet50 配置下，Sparse4D 相对对比方法的 mAP 和 NDS 分别提升 3.0% 和 2.2%；ResNet101 高分辨率配置下提升 3.2% 和 2.9%，推理速度为 8.2 FPS（StreamPETR 为 6.4 FPS）。EDA 将训练显存从 5705 MB 降至 2853 MB、完整训练时间从 23.5 小时降至 14.5 小时，并将推理速度从 13.1 FPS 提升到 19.8 FPS；验证集跟踪中，Sparse4D 相对 DORT 的 AMOTA 为 0.490 对 0.424，测试集结合 EVA02 与未来帧时达到 mAP 0.682、NDS 0.719 和 AMOTA 0.677。

## 贡献与局限

论文贡献是提出稀疏 instance-centric 4D 表示、可高效实现的 deformable aggregation/EDA、递归时序融合和无需改动检测训练的端到端跟踪，并展示其向 LiDAR、多模态及车载部署扩展的能力。局限由全文失败案例明确显示：雨夜、低光、阴影、遮挡、远距离和小目标仍会漏检，也可能把外观相似物误分类；方法还依赖相机标定，标定噪声会影响尺度估计，实际场景中的鲁棒部署仍需进一步验证。
