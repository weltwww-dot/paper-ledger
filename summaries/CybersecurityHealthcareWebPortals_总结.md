# Baseline cybersecurity configuration patterns in Italian public healthcare web portals 总结

## 基本信息
- **标题**: Baseline cybersecurity configuration patterns in Italian public healthcare web portals
- **作者**: Lerina Aversano、Alessandro Caniglia、Stefano Galantucci 等
- **期刊 / 会议**: International Journal of Information Security 2026
- **发表**: 2026-10-07
- **内容状态**: 完整 · 已基于出版社正式版全文完成中文六段式总结
- **研究方向**: 信息安全
- **DOI**: 10.1007/s10207-026-01331-0
- **PDF**: [IJIS_2026_CybersecurityHealthcareWebPortals.pdf](papers/IJIS_2026_CybersecurityHealthcareWebPortals.pdf)

## 一句话概括
研究对意大利公共医疗机构网站进行全国范围的被动安全扫描，描绘其公开可见的基线配置弱点及地域差异。结果显示，安全头、Cookie 属性和请求处理方面的低、中危问题反复出现，高危发现则较少。

## 问题与动机
区域医疗门户承载预约、支付及医疗信息等公共服务，但各地管理结构、技术栈与历史系统各异，单靠法规要求难以说明实际防护配置是否一致。既有评估若按页面或漏洞出现次数计数，也可能使页面多、服务复杂的门户显得问题更多；作者因此聚焦每类弱点是否出现在一个门户中，以便进行横向比较。

## 方法
研究依据卫生部、地区政府及公共管理名录等官方来源，人工整理并去重目标，在最终数据集中纳入 130 个可访问的公共医疗门户。作者使用 OWASP ZAP 2.16.1 的 baseline 被动扫描模式，于 2025 年 11 月 5 日单日扫描公开、未登录页面，不注入攻击载荷；每个门户的同类发现只计一次，并记录严重度、可见技术及严重度加权分数。此设计衡量的是外部可观察配置信号，不等同于漏洞可利用性或实际风险。

## 实验与结果
安全头缺失、Cookie 属性不完整及基础客户端防护问题在不同地区反复出现。宏区层面，北部、中部、南部的风险分数中位数分别为 13.0、11.0、12.0；三者高危发现数的中位数均为 0（第 16 页）。北部离散度较大，但区域分布有重叠；作者也指出，同一地区内门户差异不小，因此这些统计是配置快照，不应当作地区排名。扫描未验证告警能否被利用，数字反映的是类别覆盖与扫描器标注。

## 贡献与局限
研究提供了覆盖全国官方医疗门户的可复查被动测量流程，并展示如何以门户为单位比较基线加固情况；其数据也为后续重复扫描和纵向观察提供参照。由于只检查单一时间窗口内的未认证外部页面，研究无法观察登录后缺陷、应用业务逻辑、内部监控或补偿控制；自动扫描还可能误报或漏报。因此，作者将发现界定为提示性配置指标，而不是对实际安全态势的定论。
