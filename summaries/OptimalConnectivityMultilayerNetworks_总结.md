## 一句话概括

针对双层网络中"增加层间连边既增强鲁棒性又扩大恶意软件跨层传播路径"的权衡，本文基于图元胞自动机与 SIR 模型证明存在最大化"保持跨层连通且本地层不被感染"联合概率的最优层间边数，并提出考虑个人偏好的加权评分选边方法。

## 问题与动机

现代通信系统（物联网、信息物理系统等）普遍采用多层网络拓扑，多层化提升了网络能力与性能，但多条层间连接也会成为恶意软件跨层传播的通道，带来额外安全风险。减少层间连接可以抑制传播，却会增大网络因攻击断连而被完全隔离的风险，鲁棒性与安全性相互对立。已有工作（如按预算计算最优设计、随机节点攻击下最优跨层分配等）多不涉及攻击机制或恶意软件行为，也少显式研究这种权衡。本文在两层面框架中采用 SIR 流行病模型研究该问题，探讨是否存在最优层间边数，使网络在阻止恶意软件层间传播的同时最大化保持连通的可能性。

## 方法

- 定义两个概率测度：安全测度 PI(N)，即流行病过程达到稳态后本地层保持未感染的概率，随层间边数 N 严格递减；鲁棒性测度 PL(N)，即至少一条层间边保持未感染（两层保持连通）的概率，随 N 严格递增；并构造联合概率 PR(N) = P(I∩L)，刻画"保持跨层连通且阻止恶意软件从外部层传至本地层"。
- 论证 PR 的定义域为有限整数集（1 ≤ N ≤ |E1|·|E2|），故必存在最优边数 N* 最大化 PR，且该存在性不依赖网络的具体拓扑。
- 将双层系统行为刻画为相变：设临界阈值 k 使 PL(k) ≤ PI(k) 而 PL(k+1) ≥ PI(k+1)，系统在稀疏连接的连通受限区（PR 受 PL 制约）与高度连接的安全受限区（PR 受 PI 制约）之间发生离散切换。
- 建模采用图元胞自动机（GCA）：外部层与本地层各为 32×32（1024 节点）网格、Moore 邻域（8 邻居），层间边为连接两层不同节点的简单无向边；传播遵循经典 SIR 模型（易感者以概率 β 被感染、感染者以概率 γ 被移除，移除节点使相连层间边永久失效），感染起源于外部层并经层间边入侵本地层。
- 仿真用纯 Python 面向对象实现、运行于 PyPy v7.3.17 并并行化；对 N 从 1 到 7 各执行 15000 次 Monte Carlo 运行，每次 300 时间步以保证 S/I/R 均值收敛（绝对容差 0.01），且每次运行随机重连层间边以消除选择偏差。
- 提出加权评分方法选择最优边数：f(N) = x·PR(N) + (1−x)·PI(N)，偏好参数 x∈[0,1] 表达对鲁棒性或安全性的侧重。

## 实验与结果

- 解析基准验证（β=0、γ=0.1、I0=0.9）：PR(N) = 1 − C(I,N)/C(n,N)（n=1024，I = I0·n ≈ 922）的理论值与 Monte Carlo 结果在误差 Δ 内一致（Wald 公式 95% 置信区间，R=15000），确认仿真可靠性。
- γ=0.1、I0∈{0.1, 0.2, 0.4, 0.6} 下扫描 β：β=0.005 时最优值在 N=4（I0=0.1、0.2）且最优 N 随 I0 增大；β=0.01 时最大 PR 分别出现在 N=3（I0=0.1）与 N=4（I0=0.2），增大 β 显著压低 PR 与 PI，尤其 I0≥0.2 时最大值明显下降；β=0.02 时曲线进一步拉长、PR/PI 继续降低。
- β=0.01、γ=0.05 与 β=0.02、γ=0.1 的 S(t)/I(t)/R(t) 曲线与最优 N 高度吻合，γ=0.2 则与 β=0.005、γ=0.1 情形一致，说明 γ 减半等效于 β 加倍、γ 加倍等效于 β 减半。
- 汇总表显示 β、γ、I0 的大幅变化对最优 N 影响很小，方法对现实场景中难以精确估计的参数具有稳健性；尽管每层有 1024 个节点，最优层间边数却很少，即大型多层网络的鲁棒性与安全性仅需少量层间边即可优化。
- 应用示例（智能电网）：WSN（传感器与汇聚节点）与 SCADA 构成两层网络，初始感染 I0=2%、γ=1%、β∈{0.45%, 0.50%}，15000 次 Monte Carlo 下两种 β 的 PR(N) 最大值均出现在 N=3，即随机分布时部署 3 个汇聚节点为最优配置。
- 加权评分法示例（β=0.02、γ=0.1、I0=0.2，15 万次运行）：仅看 PR 时 N=4（43.98±0.25%）仅略高于 N=3（43.09±0.25%），但 PI 从 66.6±0.24% 降到 58.60±0.25%；取 x=0.5 时 f(N) 在 N=2 处取最大值，说明纳入 PI 与偏好可避免次优决策。

## 贡献与局限

- 提出外部层+本地层两层面框架，量化刻画"增加层间边同时提升鲁棒性并拓宽入侵通道"的矛盾。
- 通过大规模 Monte Carlo 仿真表征鲁棒性与脆弱性随连边数的变化，证明存在最优层间边数 N* 最大化"保持连通且不感染本地层"的概率，并证明其存在性不依赖具体拓扑。
- 提出基于加权评分、融合 PI、PR 与个人偏好（参数 x）的最优边数选择方法，比只优化 PR 的决策更准确。
- 将双层网络动态刻画为临界阈值处的受限区相变，验证 SIR 流行病模型能有效囊括多层网络中的鲁棒性与安全性对立关系。
- 局限：仿真限定为两层同拓扑、同规模（32×32）且 β/γ 相同的网络，层间边随机均匀连接，未覆盖多层、异构或真实复杂几何拓扑；最优边数仅对应随机分布场景，空间分布差异仍影响鲁棒性；对鲁棒性与脆弱性只给出数值刻画，未推导相变的解析阈值与分岔条件（列为未来工作）。
