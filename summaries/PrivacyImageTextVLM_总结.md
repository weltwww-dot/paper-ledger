## 一句话概括

面向云端视觉语言模型的图文对隐私泄露威胁，提出用户指令驱动的多模态隐私保护框架，用代理模型定位敏感区域并结合频域去特征与语义化文本扰动，实现不低于 96% 的效用保持。

## 问题与动机

用户在云端视觉语言模型（VLM）上上传的图文对常含人脸、位置等敏感个人信息，第三方攻击者可通过网络截获或未授权访问服务器存储获得这些数据，再利用预训练 VLM 提取隐私。传统的隐私保护方法将文本与图像两种模态割裂处理，无法应对图文间固有的语义对齐：只保护单一模态时，攻击者可从未受保护模态中推断敏感内容；而对图像全面过度遮蔽又会严重损害下游任务性能。现有针对 VLM 的尝试（如指令改写、仅保留文本）要么牺牲视觉推理能力，要么缺乏跨模态的对齐式保护，尚无方法能同时为图像与文本提供语义对齐的隐私防护。

## 方法

提出一种运行在用户侧的、由用户指令驱动的图文隐私保护框架。先用词性标注识别文本中的隐私敏感 token（名词/代词，依据 GDPR、ISO/IEC 27701:2019、我国个人信息保护法等），再由本地代理 VLM（CLIP、BLIP、BLIP2）通过跨模态注意力把隐私 token 定位到对应图像区域（高斯模糊平滑，注意力阈值 0.6）；若用户未附带文本，代理模型先生成图像描述再定位。图像侧采用 JPEG 风格的分块离散余弦变换（BDCT）：图像统一为 384×384、划分 8×8 分块后转入频域，以图像信息熵为约束（熵阈值 ε，默认 0.5）按 R/G/B 通道独立去除频率通道并打乱重组，再经逆 DCT 还原，实现效用与隐私的平衡。文本侧采用 Text-to-Text（T2T）框架：向 token 向量加入拉普拉斯噪声，并引入同词性语义近邻 token 的加权约束机制以保持语法结构与语义连贯。受保护图文对随后上传云端 VLM，仅微调其最后一个视觉层与最后一个 LLM 层即可恢复任务能力。

## 实验与结果

在 MS-COCO（图像描述，16,000 张图、12,000 训练/2,000 验证/2,000 测试）、LLaVA-300K（VQA，80/20 划分）、PhotoChat++ 与 Conceptual Captions 上，对 BLIP2、Llama-3.2-Vision-Instruct、LLaVA-v1.5-7B、Qwen2-VL 等模型以 BLEU-4、ROUGE-1/2/L 与 GPT-4/GPT-4o 评分为指标评估。效用方面：VQA 中四个模型平均保持原始图文对基线 GPT 评分的 96.17%（如 Qwen-2b 66.89 对 69.52）；在 PhotoChat++ 与 Conceptual Captions 上微调模型取得 69.91 与 77.34 分，平均保持 96.54% 效用，而未微调（Protected，模拟无分布访问权的攻击者）的模型评分大幅下降（如 Qwen-2b 仅 22.48）。隐私方面：针对直接推理与对抗性提示两类多模态攻击，受保护数据使攻击者 VLM 性能显著退化；对 Real-ESRGAN 与 InstructIR 图像重建攻击，本方法重建相似度更低（Real-ESRGAN 下 SSIM 0.7170、PSNR 21.76、MSE 437.36），优于差分隐私基线（其噪声接近扩散模型去噪机制故防御弱），而过度遮蔽的 FaceObfuscator 虽抵抗重建最强却严重损失效用；对 BERT 黑盒、Token Embedding 反演与属性推断三类文本攻击，当 η≤2（采用的参数）时攻击成功率降至近 0%。敏感性分析显示熵阈值 ε=0.5 达到最优平衡（ε=0.3 时 GPT-4o 评分降至 0.3525 但防御更强）；与 RAPT、差分隐私等文本基线相比，同等噪声下本方法取得更高评分；消融表明代理模型选择影响较小（CLIP 61.18、BLIP 60.93、BLIP2 58.87，无定位仅 44.25），文本引导定位不可或缺。

## 贡献与局限

贡献：提出首个面向多模态视觉问答场景的实用隐私保护框架，提供个性化（按用户指令）保护且维持至少 96% 的模型效用；以 BDCT 频域去特征保留有用视觉特征并去除敏感视觉信息，以近邻 token 语义保持文本语法结构与上下文连贯；系统验证了受保护图文对可显著降低第三方模型表现并抵御多种攻击（重建、属性推断、成员推断、隐私 token 预测等）。局限：基于词性的隐私 token 识别可能遗漏动词短语或复杂语境中的隐私信息；跨模态注意力定位存在漏检（抽象或隐含线索、14×14 patch 粒度限制）与误检，未命中的敏感区域将不被保护；医学与生物特征图像因监管框架不同未纳入评估；未来拟扩展到音频等其他模态，并引入轻量级定位模型（如 Qwen3-VL-2B-Instruct、Gemma3-4B）结合 RAG 以支持边缘部署。
